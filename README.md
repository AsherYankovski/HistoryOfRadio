# Что это?
Это репозиторий игры-пазла, посвящённой сборке радиоустройств и направленной на изучение их базового устройства.\
Разработка ведётся на Godot, на языке GDScript.

# Источники вдохновения
Этот проект в основном вдохновлён двумя популярными играми: [Restory](https://store.steampowered.com/app/3812600/ReStory_Chill_Electronics_Repairs/) и [Turing complete](https://store.steampowered.com/app/1444480/Turing_Complete/).

# Основыне механики
Из Restory проект наследует сборку 3D моделей электронных устройств с минималистичным дизайном.\
Из Turing Complete – сборку логических цепей, с постепенным использованием более сложных блоков, которые собираются игроком в ходе игры.
